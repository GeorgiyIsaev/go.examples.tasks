Data Structures and Algorithms

1. Удалить дубликаты с сохранением порядка
   Условие: Дан []int. Вернуть новый срез без повторов, сохранив порядок первых вхождений.
   Пример: [1,2,1,3,2,4] -> [1,2,3,4]
   Сигнатура:
   go
   func Dedup(nums []int) []int
   Что проверяет: map, append, пустой/nil срез, аккуратность с памятью.
   Сложность: O(n).
________________________________________
2. Two Sum
   Условие: Дан []int и target. Вернуть индексы двух чисел, которые в сумме дают target. Ровно одно решение.
   Пример: nums = [2,7,11,15], target = 9 -> [0,1]
   Сигнатура:
   go
   func TwoSum(nums []int, target int) []int
   Что проверяет: map, один проход, обработка отсутствия решения.
   Сложность: O(n).
________________________________________
3. Группировка анаграмм
   Условие: Дан []string из строчных латинских букв. Сгруппировать слова, которые являются анаграммами. Порядок групп и слов внутри группы не важен.
   Пример:
   ["eat","tea","tan","ate","nat","bat"] -> [["eat","tea","ate"], ["tan","nat"], ["bat"]]
   Сигнатура:
   go
   func GroupAnagrams(words []string) [][]string
   Что проверяет: map, ключ через [26]int или сортировку, работа со срезами.
   Сложность: O(n * k), если ключ — массив частот.
________________________________________
4. Слияние интервалов
   Условие: Дан [][]int интервалов вида [start, end]. Слить пересекающиеся интервалы, вернуть отсортированный по началу результат.
   Пример:
   [[1,3],[2,6],[8,10],[15,18]] -> [[1,6],[8,10],[15,18]]
   Сигнатура:
   go
   func MergeIntervals(intervals [][]int) [][]int
   Что проверяет: sort.Slice, проход, граничные случаи: пустой вход, один интервал, касание [1,2],[2,3].
   Сложность: O(n log n).
________________________________________
5. RLE-сжатие строки
   Условие: Дана строка из строчных латинских букв. Вернуть сжатие: символ + количество подряд идущих. Количество писать всегда.
   Пример:
   "aaabbc" -> "a3b2c1"
   "abcd" -> "a1b1c1d1"
   Сигнатура:
   go
   func Compress(s string) string
   Что проверяет: strings.Builder, цикл, работа с rune/byte, пустая строка.
   Сложность: O(n).
________________________________________

6. Проверка правильности скобок
   Условие: Дана строка, состоящая только из символов (, ), {, }, [, ]. Вернуть true, если скобки расставлены корректно: каждая открывающая закрыта соответствующей закрывающей, и порядок вложенности соблюдён.
   Примеры:
   •	"()" → true
   •	"()[]{}" → true
   •	"([{}])" → true
   •	"(]" → false
   •	"([)]" → false
   •	"(" → false
   •	"" → true
   Сигнатура:
   go
   func IsValid(s string) bool
   Что проверяет: использование среза как стека (append + срез по последнему элементу), map для пар скобок, обработку пустой строки и «висящих» открывающих/закрывающих скобок.
   Сложность: O(n) по времени, O(n) по памяти.
   Типичные ловушки:
   •	Забыть проверить, что стек пуст в конце ("(" не должен вернуть true).
   •	Забыть проверить, что стек не пуст перед pop (иначе паника на ")").
   •	Путать byte и rune — здесь достаточно byte, но нужно уметь объяснить почему.
