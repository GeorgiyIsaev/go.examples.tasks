# 02. Sliding Window (Скользящее окно)

## Что это

Паттерн «скользящее окно» — это приём, когда мы поддерживаем
некоторую **непрерывную область** массива или строки (окно) и
двигаем её границы по определённым правилам. Вместо того чтобы
на каждой итерации пересчитывать всё окно с нуля за O(k), мы
обновляем состояние **инкрементально**: убрали один элемент слева,
добавили один справа.

Ключевое преимущество — O(n) вместо O(n·k).

## Почему это работает

Задача часто формулируется так: «найти подмассив/подстроку с
некоторым свойством». Наивный подход — перебрать все O(n²) подмассивов
и для каждого посчитать свойство за O(n), итого O(n³). Или O(n²) с
префиксными суммами. Окно даёт O(n).

Правило такое:

- Если **при увеличении окна свойство меняется монотонно** (сумма
  растёт, количество уникальных символов не убывает, количество
  нулей не убывает и т. д.) — окно применимо.
- Если свойство **немонотонно** (например, сумма подмассива с
  отрицательными числами — может и упасть, и вырасти) — окно
  **не работает**, нужны префиксные суммы (p18).

## Три подварианта

### 1. Fixed Window — фиксированный размер

```
[1, 2, 3, 4, 5, 6, 7] k = 3
    [-----] окно [1,2,3]
[-----] окно [2,3,4]
[-----] окно [3,4,5]
```


Размер окна **постоянен**. Двигаем по одному шагу вправо: убрали
`nums[i-k]`, добавили `nums[i]`.

**Когда:** «k последовательных», «среднее по k», «максимум в окне длины k».

**Примеры задач:**
- Maximum Sum of K Consecutive Elements
- Find Averages of Subarrays
- Maximum Vowels in Substring of Length k

**Сложность:** O(n) время, O(1) память.

---

### 2. Variable Window (Longest) — растущее окно, ищем максимум


```
"abcabcbb"
[---] "abc", длина 3
[---] "bca", длина 3
[---] "cab", длина 3
[---] "abc", длина 3
[---] "bcb" — повтор, сжимаем
```


Окно **расширяется вправо**, пока свойство выполняется. Как только
нарушено — сдвигаем `left`, пока не восстановится. Ответ обновляем
на каждом шаге.

**Когда:** «самая длинная подстрока с условием», «максимальная
длина окна», «наибольшее количество».

**Примеры задач:**
- Longest Substring Without Repeating Characters
- Longest Repeating Character Replacement
- Max Consecutive Ones III
- Longest Substring with At Most K Distinct Characters

**Сложность:** O(n) время (каждый элемент входит и выходит один раз).

---

### 3. Min Window — сжимающееся окно, ищем минимум

```
"ADOBECODEBANC", t = "ABC"
[--------] есть "ABC" — длина 7
[-------] уже нет — оставляем
[---] "ODEB" — нет
[---] "EBA" — нет
[----] "BANC" — да, длина 4
```


Окно **расширяется вправо**, пока не выполнит условие. Как только
выполнило — пытаемся сжать слева, обновляя минимум. Продолжаем.

**Когда:** «минимальная подстрока, содержащая ...», «минимальная
длина окна, при которой ...», «наименьшее окно с условием».

**Примеры задач:**
- Minimum Window Substring
- Minimum Size Subarray Sum
- Smallest Subarray with Sum >= K

**Сложность:** O(n) время, O(k) память (k — размер алфавита).

## Признаки, что нужен sliding window

- Слова **«подмассив»**, **«подстрока»**, **«непрерывный»**.
- Слова **«окно»**, **«диапазон»**, **«длина»**.
- Свойство **монотонно**: чем больше окно, тем «сильнее» свойство
  (или наоборот).
- Нужно оптимизировать O(n²) → O(n).

## Признаки, что НЕ нужен

- **Отрицательные числа и сумма.** С ними сумма не монотонна,
  окно ломается. Используйте префиксные суммы (p18).
- **Подпоследовательность**, а не подмассив (можно удалять элементы).
- **Нужны все** подмассивы, а не агрегат (максимум/минимум).
- Массив **не отсортирован** и задача про пары, а не окна.

## Общий шаблон

### Fixed

```go
// Первое окно
sum := 0
for i := 0; i < k; i++ {
    sum += nums[i]
}
// ...
for i := k; i < len(nums); i++ {
    sum += nums[i] - nums[i-k]    // сдвиг
    // обновление ответа
}
```

### Variable (longest)
```go
left := 0
for right := 0; right < len(nums); right++ {
    // добавили nums[right]
    for окно_нарушено {
        // убрали nums[left]
        left++
    }
    // обновили максимум
}
```



### Min Window
```go
left := 0
for right := 0; right < len(nums); right++ {
    // добавили nums[right]
    for окно_удовлетворяет_условию {
        // обновили минимум
        // убрали nums[left]
        left++
    }
}
```

### Типичные ловушки
Применить окно к массиву с отрицательными числами.
Классика: [1, -1, 5, -2, 3], target=3. Окно не сработает.
Пример, где окно ломается: MinSubArrayLen с отрицательными.

Условие сжатия окна неправильное.
Например, в LongestOnes надо проверять zeros > k, а не
zeros >= k. Легко спутать.

Забыть обновлять ответ на каждой итерации.
Ответ надо пересчитывать и когда окно растёт, и когда сжимается.
В MinWindow — внутри внутреннего цикла. В LongestSubstring —
после внутреннего.

Условие pos >= left в LengthOfLongestSubstring.
Если символ был в map, но до текущего окна — не двигаем
left. Без этой проверки окно сломается на "abba".

Забыть про пустой вход.
len(s) == 0, k == 0, len(nums) < k — отдельные случаи.

left++ без изменения состояния.
Если окно не сжимается, а left двигается — состояние и окно
разойдутся. Каждый шаг left++ должен сопровождаться
«удалением» элемента из состояния (вычитанием, count--,
delete и т. д.).

Не хранить «что именно» в окне.
В LengthOfLongestSubstring одного счётчика повторяющихся
символов мало — нужно знать позицию последнего вхождения.
Отсюда map[byte]int, а не map[byte]bool.

### Связанные паттерны
Two Pointers (p01) — похож, но указатели двигаются навстречу
или в одном направлении с разными скоростями. В окне оба указателя
двигаются в одну сторону, но с разной целью: right расширяет,
left сжимает.

Prefix Sum (p18) — используется там, где окно не работает
(отрицательные числа, сумма подмассива).

Hash Map (p09) — окно часто хранит состояние в виде map
(частоты, последние позиции).

## Мини-упражнение
Попробуйте без подсказки:

Дан массив [1,3,2,6,-1,4,1,8,2] и k=5. Найдите максимальное
среднее подмассива длины ровно k. (Fixed)

Дан [2,3,1,2,4,3] и target=7. Найдите минимальную длину
подмассива с суммой >= target. (Min Window)

Дана строка "aababba" и k=1. Найдите длину самой длинной
подстроки, где можно заменить не более k символов, чтобы
все стали одинаковыми. (Variable)

Дана строка и число k. Найдите длину самой длинной подстроки,
в которой каждая буква встречается не чаще k раз. (Variable,
чуть сложнее — подумайте, монотонно ли свойство.)
