# 01. Two Pointers (Два указателя)

## Что это

Паттерн «два указателя» — это приём, когда мы заводим два индекса
(указателя) в массиве или строке и двигаем их по определённым правилам,
пока не найдём ответ или не обработаем весь вход.

Вместо того чтобы перебирать все пары элементов за O(n²), мы
используем структуру данных или свойство входных данных, чтобы
сократить количество проверок до O(n).

## Три варианта паттерна

### 1. Opposite Ends — указатели навстречу

```
  [1, 2, 3, 4, 5]
   ↑  ↑
left  right
```

`left` идёт слева направо, `right` — справа налево. На каждом шаге
один из них сдвигается, пока они не встретятся.

**Когда:** отсортированный массив, поиск пары, разворот, проверка
палиндрома, in-place модификация с двух концов.

**Примеры задач:**
- Two Sum на отсортированном массиве
- Valid Palindrome
- Reverse String
- Container With Most Water
- 3Sum (два указателя внутри)

**Сложность:** O(n) время, O(1) память.

----------------------------------------

### 2. Slow / Fast — указатели в одном направлении

```
[1, 1, 2, 3, 3, 4]
↑ ↑
slow fast
```

`fast` бежит впереди и читает, `slow` плетётся сзади и пишет только
те элементы, которые нужно оставить. Между ними образуется «дырка»
из мусора, которую потом можно игнорировать.

**Когда:** удаление элементов in-place, «сжатие» среза, поиск цикла
(Floyd's algorithm на связном списке).

**Примеры задач:**
- Remove Duplicates from Sorted Array
- Move Zeroes
- Remove Element
- Linked List Cycle (вариант Floyd)

**Сложность:** O(n) время, O(1) память.

---

### 3. Three Pointers — три указателя

Два подварианта:

**А) Фиксированный + два навстречу** (для Three Sum):

```
[-1, 0, 1, 2, -1, -4] → после сортировки → [-4, -1, -1, 0, 1, 2]
i l r
```

Фиксируем `i`, на оставшейся части запускаем противоположные
указатели. Получаем O(n²).

**Б) Dutch National Flag** (для Sort Colors):

```
[0, 0, ..., 1, 1, ..., 2, 2, ...]
↑ ↑ ↑
low mid high
```



Три указателя делят массив на три зоны: 0-ки, 1-ки, 2-ки. Один
проход, O(n).

**Примеры задач:**
- 3Sum, 4Sum
- Sort Colors (Dutch National Flag)
- Partition Array

**Сложность:** O(n²) для 3Sum, O(n) для Sort Colors.

---

## Признаки, что нужен Two Pointers

- Массив **отсортирован** (или можно отсортировать).
- Задача про **пару**, **тройку**, **симметрию**.
- Нужно сделать **in-place**, без дополнительной памяти.
- Слова «найти два элемента», «разделить», «сжать», «развернуть».
- Массив большой, а наивное O(n²) не подходит.

## Признаки, что НЕ нужен

- Нужна **сумма подмассива** с отрицательными числами → скользящее окно
  не работает, но и Two Pointers тоже не подходит — нужны префиксные суммы.
- Требуется **отсортировать** сам массив → используйте сортировку.
- Нужно найти **все** подмассивы → возможно, другая техника.

## Общий шаблон

### Opposite ends

```go
left, right := 0, len(nums)-1
for left < right {
    // посмотреть на nums[left], nums[right]
    // решить, что двигать
    if условие { return ответ }
    else if сумма < target { left++ }
    else { right-- }
}
```
### Slow / fast
```go
slow := 0
for fast := 0; fast < len(nums); fast++ {
    if nums[fast] != пропустить {
    nums[slow] = nums[fast]
    slow++
    }
}
return slow   // новая длина
``````
### Three Sum 

```go
sort.Ints(nums)
for i := 0; i < n-2; i++ {
    if i > 0 && nums[i] == nums[i-1] { continue }  // дедуп i
    left, right := i+1, n-1
    for left < right {
        sum := nums[i] + nums[left] + nums[right]
        // сдвигаем left или right + дедуп
    }
}
```

## Типичные ловушки
Забыть отсортировать массив, если задача требует.
Без сортировки left++ при sum < target не имеет смысла.

Путать left < right и left <= right.
В reverse/palindrome — <, потому что при == уже середина,
менять нечего. В некоторых задачах (например, поиск элемента) — <=.

Забыть дедупликацию в Three Sum.
Дубликаты появляются на двух уровнях: внешний i и внутренние
left/right. Оба нужно пропускать.

Мутировать входные данные там, где не разрешено.
Если задача просит вернуть новый массив — не сортируйте вход,
сделайте копию.

Не проверить пустой вход.
nums[0] при len == 0 — паника. nums[left] при left == right
после цикла — тоже может быть паникой.

Считать, что сдвиг всегда в одну сторону.
В opposite ends — «если сумма меньше, left++». В slow/fast —
«если элемент не тот, fast++, иначе пишем и slow++».
Условия разные.

## Связанные паттерны
Скользящее окно (p02) — тоже два указателя, но оба двигаются
в одном направлении и окно растёт/сжимается. Отличие: Two Pointers
работает с фиксированной позицией, окно — с изменяющейся областью.

Бинарный поиск (p04) — тоже сближающиеся указатели, но шаг
вычисляется как mid, а не ±1.

Префиксные суммы (p18) — используются там, где Two Pointers
не работает (отрицательные числа).


## Мини-тесты для самопроверки

Проверь себя — сможешь ли решить за 15 минут каждую:
1.	Valid Palindrome — дана строка, проверить палиндром, игнорируя регистр и не-буквы.
2.	Two Sum II — отсортированный массив, найти пару с суммой = target.
3.	Container With Most Water — max площадь между двумя вертикалями.
4.	Remove Duplicates — удалить дубликаты in-place.
5.	3Sum — все тройки с суммой 0.


## Шаблон-напоминание для собеса
Когда увидел задачу — задай себе 3 вопроса:
1.	Отсортирован ли ввод? Если нет — можно ли отсортировать, не потеряв ответ?
2.	Нужна пара/тройка? Если да — two pointers.
3.	Нужно in-place без доп. памяти? Если да — slow/fast.
      Если все три «да» — это Two Pointers, действуй.
