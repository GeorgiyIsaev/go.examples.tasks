01. Two Pointers (Два указателя)
    🎯 Когда применять
    •	Работаешь с отсортированным массивом/строкой.
    •	Нужно найти пару/тройку элементов с условием (сумма, разность, произведение).
    •	Нужно сравнить с двух концов (палиндром, разворот).
    •	Нужно убрать дубликаты in-place (без доп. памяти).
    •	Задача про сортированный ввод → почти всегда two pointers.
    Ключевой сигнал: «массив отсортирован» + «найти пару/тройку» + «O(n) без доп. памяти».
    📊 Сложность
    Время	Память
    Два указателя	O(n)	O(1)
    Наивный перебор	O(n²)	O(1)
    🧩 Три варианта
    Вариант A: с двух концов (opposite ends) 
```go
    // Найти пару с суммой = target в отсортированном массиве
    func twoSumSorted(nums []int, target int) (int, int, bool) {
    l, r := 0, len(nums)-1
    for l < r {
    sum := nums[l] + nums[r]
    switch {
    case sum == target:
    return l, r, true
    case sum < target:
    l++          // нужно больше → двигаем левый вправо
    default:
    r--          // нужно меньше → двигаем правый влево
    }
    }
    return -1, -1, false
    }
    Как думать: сумма маленькая → увеличиваем (l++), большая → уменьшаем (r--).
    Вариант B: медленный и быстрый (same direction)
    go
    // Удалить дубликаты in-place из отсортированного массива
    // Возвращает новую длину
    func removeDuplicates(nums []int) int {
    if len(nums) == 0 {
    return 0
    }
    slow := 0
    for fast := 1; fast < len(nums); fast++ {
    if nums[fast] != nums[slow] {
    slow++
    nums[slow] = nums[fast]
    }
    }
    return slow + 1
    }
    Как думать: slow — куда писать, fast — что читать.
    Вариант C: 3 указателя (для тройки/разворота)
    go
    // Развернуть массив in-place
    func reverse(nums []int) {
    for l, r := 0, len(nums)-1; l < r; l, r = l+1, r-1 {
    nums[l], nums[r] = nums[r], nums[l]
    }
    }

// 3Sum: найти все тройки с суммой 0
func threeSum(nums []int) [][]int {
sort.Ints(nums)
var res [][]int
for i := 0; i < len(nums)-2; i++ {
if i > 0 && nums[i] == nums[i-1] {
continue                    // пропуск дубликатов
}
l, r := i+1, len(nums)-1
for l < r {
sum := nums[i] + nums[l] + nums[r]
switch {
case sum == 0:
res = append(res, []int{nums[i], nums[l], nums[r]})
l++
r--
for l < r && nums[l] == nums[l-1] { l++ }
for l < r && nums[r] == nums[r+1] { r-- }
case sum < 0:
l++
default:
r--
}
}
}
return res
}
```
🧠 Обобщённый скелет
```go
func twoPointers(nums []int, target int) int {
l, r := 0, len(nums)-1

    for l < r {                    // или l <= r — зависит от задачи
        // 1) вычислить что-то из nums[l], nums[r]
        // 2) решить, что двигать:
        //    - оба (нашли ответ)
        //    - l++ (нужно больше)
        //    - r-- (нужно меньше)
        //    - l++, r-- (внутри цикла)
    }
    
    return result
}
```

Правило: условие l < r vs l <= r — зависит от того, может ли l и r указывать на один элемент. Для пары — <. Для поиска элемента в одном массиве — <=.
📝 Классические задачи
Задача	Что использовать
Two Sum II (sorted)	Два конца
3Sum / 4Sum	Сортировка + 3 указателя
Container With Most Water	Два конца, двигаем меньший
Valid Palindrome	Два конца, сравнение
Remove Duplicates	Slow / fast
Move Zeroes	Slow / fast
Sort Colors (Dutch flag)	Три указателя (low, mid, high)
Trapping Rain Water	Два конца + максимумы
Reverse String	Два конца
Squares of Sorted Array	Два конца с конца
⚠️ Подводные камни
```go
// 1) Забыл сдвинуть указатель → бесконечный цикл
for l < r {
// что-то делаем
// ❌ забыли l++ или r--
}

// 2) l++ в неправильную сторону
// nums отсортирован по возрастанию, ищем пару sum=10
// nums[l]+nums[r] = 3 < 10 → нужно БОЛЬШЕ → l++
// nums[l]+nums[r] = 20 > 10 → нужно МЕНЬШЕ → r--

// 3) Пропуск дубликатов (для 3Sum и подобных)
// Сравнивай с ПРЕДЫДУЩИМ, а не со следующим
if i > 0 && nums[i] == nums[i-1] { continue }   // ✅
// if i < len-1 && nums[i] == nums[i+1] { }     // ❌ хуже

// 4) Индексы vs значения — не путай
if nums[l] == target { }   // значение
if l == target { }         // индекс (обычно ошибка)

// 5) Off-by-one при l <= r
// Для поиска пары l < r
// Для поиска одного элемента l <= r (binary search)

// 6) Массив НЕ отсортирован — сначала sort!
sort.Ints(nums)            // O(n log n), потом O(n)

// 7) Для строк — руны vs байты
s := []rune(str)           // если работаешь с Unicode
l, r := 0, len(s)-1
```
🔗 Связь с другими паттернами
•	Sliding Window — частный случай двух указателей, где важен «интервал».
•	Binary Search — тоже два указателя (lo, hi), но прыгают в середину.
•	Fast & Slow — два указателя с разной скоростью (для циклов в linked list).
•	Merge Intervals — сортировка + проход с двумя указателями.

🧪 Мини-тесты для самопроверки

1.	Valid Palindrome — дана строка, проверить палиндром, игнорируя регистр и не-буквы.
2.	Two Sum II — отсортированный массив, найти пару с суммой = target.
3.	Container With Most Water — max площадь между двумя вертикалями.
4.	Remove Duplicates — удалить дубликаты in-place.
5.	3Sum — все тройки с суммой 0.


    📌 Шаблон-напоминание для собеса
Когда увидел задачу — задай себе 3 вопроса:
1.	Отсортирован ли ввод? Если нет — можно ли отсортировать, не потеряв ответ?
2.	Нужна пара/тройка? Если да — two pointers.
3.	Нужно in-place без доп. памяти? Если да — slow/fast.
      Если все три «да» — это Two Pointers, действуй.
