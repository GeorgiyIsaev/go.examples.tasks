## Как учиться (методика на один паттерн)

1. **Теория.** Прочитай `README.md` паттерна от начала до конца.
2. **Словесный алгоритм.** Зачитай его вслух и воспроизведи вслух же —
   пока не сможешь сказать по шагам, не глядя. Это главное упражнение:
   на собесе говорят вслух, а не печатают.
3. **Код по подпапкам.** Запусти каждую вариацию отдельно:
   `go run ./название_подпапки`, посмотри на вывод, потом открой код.
   Убедись, что тесты зелёные: `go test ./...`.
4. **Устные мини-задачи** в конце README — без кода, мысленно рисуя указатели/окно/дерево.
5. **LeetCode-блок** — решить минимум 3 задачи из списка (номера и условия есть в README,
   решений там нет — специально).
6. **Через 2–3 дня** вернуться и повторить пп. 2 и 4 вслух, не открывая README.

## Критерий «паттерн выучен»

- Называю **признаки задачи** (какими словами в условии паттерн выдаёт себя).
- Воспроизвожу **словесный алгоритм** вслух, без подсказки.
- Называю **типичные ловушки** этого паттерна (минимум 3).
- Решаю **3+ LeetCode** из блока за ≤ 20 минут каждый.

## Порядок изучения (блоки, а не по номерам)

Учить подряд по номерам неэффективно — блоки связаны сильнее, чем соседние номера.

| Блок | Паттерны | Зачем вместе |
|---|---|---|
| **A. Указатели и области** | 01 → 02 → 04 | все три про «сужение пространства»: ±1, окно, деление пополам. После блока A чувствуется, как инвариант удерживает ответ |
| **B. Хэши и стеки** | 09 → 10 → 12 | от простого map к стеку и монотонному стеку |
| **C. Графы** | 05 → 06 → 07 → 08 | обходы, затем откат, затем порядок в DAG |
| **D. Динамика** | 14 → 15 | от 1D-массива состояния к 2D-таблице; перед этим обязательно 16 (жадность) как контраст |
| **E. Специальное** | 11, 13, 17, 18, 19 | независимые приёмы, можно чередовать с другими блоками |

Текущее место: **блок A завершён** (01–04). Дальше — блок B, начиная с 09 Hash Map
(он нужен почти всем остальным).

## Как держать навык

- **Ротация:** 10–15 минут вслухого воспроизведения одного старого алгоритма в день
  (случайный паттерн из выученных) — лучше, чем решать новое подряд.
- **Смешанные тренировки:** бери задачи из разных паттернов вперемешку —
  на собесе же не скажут, какой паттерн применять.
- **Тайминг:** easy ≤ 10 мин, medium ≤ 20 мин. Не уложился — перечитай «Ловушки»
  в README паттерна и реши ещё раз.
- **Свой банк решений:** в [`../coding/`](../coding/) лежат учебные задачи с условиями
  (12 штук) — решай их без подсказок, это и есть «закрепление без решений».
